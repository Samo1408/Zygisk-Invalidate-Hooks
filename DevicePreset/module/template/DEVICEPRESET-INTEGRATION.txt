DevicePreset companion app integration
======================================

Module ID / install path: inline_hook_spoof
Display name: DevicePreset
Shared property file: /data/adb/modules/inline_hook_spoof/config/device.prop
Editable source profile: /data/adb/modules/inline_hook_spoof/config/devicepreset-profile.json

The companion app writes both files atomically after verifying module.prop exists and the module is enabled.
post-fs-data.sh consumes config/device.prop through resetprop-rs --if-diff.
The app reloads devicepreset-profile.json on launch so the last saved profile remains editable.
Existing config.txt remains reserved for the original Zygisk package-selection configuration.
Protected property keys remain skipped: ro.product.hardware, ro.hardware, ro.board.platform, ro.boot.board.platform.
The bundled resetprop-rs binary supports ARM64-v8a only.
